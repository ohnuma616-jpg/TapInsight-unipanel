# TapInsight

TapInsight は、RayNeo X3 Pro AR グラス向けの AI アシスタントアプリです。Google Gemini とグラスのカメラ・マイクを連携させ、ハンズフリーで音声や映像に関する質問に答えます。通常の質問モードに加え、グラスのカメラ映像を見ながらリアルタイムに応答する会話モードも利用できます。

インターネットラジオ（ジャンル検索・お気に入り機能付き）、AR 向けブラウザー、プレイリストや読み上げに対応した端末内メディアライブラリーも搭載しています。自分で運用する OpenClaw AI エージェントと連携して、スマートホームや自動化タスクを実行することもできます。スマートフォンや PC から設定するためのコンパニオン Web アプリはグラス上で動作し、Wi-Fi または USB 経由でアクセスできます。

## 操作方法

- シングルタップ：選択、リンクを開く、入力欄にフォーカスするなどの操作
- ダブルタップ：戻る、ダイアログを閉じる、一覧に戻る
- 左右にスワイプ：横方向にスクロール、タブを切り替える
- 上下にスワイプ：コンテンツをスクロールする

## クレジット

`tapbrowser` モジュールは、InformalTech と glxblt76 が公開している RayNeo X3 Pro 向け AR ブラウザー [TapLinkX3](https://github.com/informalTechCode/TAPLINKX3) を基にしています。
